# Глоссарий терминов

Этот глоссарий содержит определения терминов и концепций, используемых в технической спецификации системы авторизации.

---

## А

- **Access Token (Токен доступа)** — JWT токен, который используется для аутентификации пользователя в API. Срок действия: 30 минут. Передаётся в заголовке `Authorization: Bearer <token>`. [см. 02-jwt.md](./02-jwt.md)

- **API Gateway** — прокси-сервер, который принимает входящие HTTP/HTTPS запросы, выполняет rate limiting и SSL termination, затем перенаправляет запросы на application server. [см. 01-architecture.md](./01-architecture.md)

- **Argon2id** — современный алгоритм хэширования паролей, который использует много памяти (memory-hard), делая взлом методом перебора крайне сложным. Используется в проекте с параметрами: memory=64MB, iterations=3, parallelism=4. [см. 05-security.md](./05-security.md)

- **Argon2id параметры:**
  - `memory_cost=65536` — 64MB памяти на хэш
  - `time_cost=3` — 3 итерации
  - `parallelism=4` — 4 параллельных потока

- **Audit Logging** — логирование всех критических операций (регистрация, вход, выход, смена пароля) для возможности последующего аудита безопасности. [см. 07-logging.md](./07-logging.md)

- **Auto-refresh** — автоматическое обновление access token, если он истек менее 5 секунд назад и запрос использует "безопасный" метод (GET, HEAD, OPTIONS). [см. 02-jwt.md](./02-jwt.md)

---

## B

- **Bcrypt** — алгоритм хэширования паролей, более старый чем Argon2id. Использует Adaptive Cost Factor. В проекте используется Argon2id как более современная альтернатива.

- **BullMQ** — очередь задач на базе Redis, используемая для асинхронной обработки email-рассылок при высокой нагрузке. [см. 06-email.md](./06-email.md)

---

## C

- **CSRF (Cross-Site Request Forgery)** — атака, при которой злоумышленник заставляет пользователя выполнить нежелательные действия в приложении, где он авторизован. Защита: SameSite=Strict cookies + Origin validation. [см. 05-security.md](./05-security.md)

- **CSRF Token** — уникальный случайный токен, который генерируется сервером и проверяется при каждом чувствительном запросе для защиты от CSRF-атак.

- **CORS (Cross-Origin Resource Sharing)** — механизм, который контролирует, какие веб-приложения могут делать запросы к вашему API. В проекте используется white-list разрешённых origins. [см. 05-security.md](./05-security.md)

- **Clickjacking** — атака, при которой пользователь нажимает на невидимую или перекрытую кнопку, выполняющую нежелательное действие. Защита: заголовок `X-Frame-Options: DENY`. [см. 05-security.md](./05-security.md)

- **Cookie domain** — домен, для которого отправляется cookie. В проекте: `api.mystore.com`. [см. 02-jwt.md](./02-jwt.md)

- **Cookie SameSite=None** — режим, позволяющий отправку cookie при cross-site запросах (требует `Secure` флаг). Используется для API, вызываемого с других доменов.

---

## D

- **Database Schema** — структура базы данных, включающая таблицы (users, refresh_tokens, email_verification_tokens и др.) и связи между ними. [см. 03-database.md](./03-database.md)

- **Database Migration** — процесс управления изменениями в структуре базы данных (создание таблиц, изменение колонок). В проекте используется SQL-миграции.

- **DNS** — система доменных имен, переводит человекочитаемые имена (mystore.com) в IP-адреса серверов.

---

## E

- **E2E (End-to-End) Tests** — тесты, которые имитируют реальное поведение пользователя от начала до конца, включая взаимодействие с UI (Cypress/Playwright). [см. 10-testing.md](./10-testing.md)

- **Email Queue** — очередь email-сообщений, которая обрабатывается асинхронно, чтобы не блокировать основной поток выполнения запроса. В проекте используется BullMQ. [см. 06-email.md](./06-email.md)

- **Environment Variables** — переменные конфигурации (DATABASE_URL, JWT_PRIVATE_KEY, SMTP_PASS и др.), которые хранятся вне кода и загружаются при запуске приложения. [см. 08-deployment.md](./08-deployment.md)

- **Event Schema** — структура логов, описывающая, какая информация должна быть записана при каждом событии (timestamp, event, user_id, ip_address и др.). [см. 07-logging.md](./07-logging.md)

---

## F

- **FIDO2 / WebAuthn** — стандарты для аутентификации с помощью биометрии (отпечаток пальца, FaceID) или физических ключей (YubiKey).

---

## G

- **GDPR (General Data Protection Regulation)** — европейский регламент по защите персональных данных, требует возможности удаления аккаунта пользователя (см. раздел 4.12 DELETE /v1/auth/me). [см. 05-security.md](./05-security.md)

- **GET, POST, PUT, DELETE** — HTTP методы: GET (получить), POST (создать), PUT (обновить), DELETE (удалить).

---

## H

- **HSTS (HTTP Strict Transport Security)** — заголовок безопасности, который заставляет браузер всегда использовать HTTPS для связи с сервером (`max-age=31536000; includeSubDomains`). [см. 05-security.md](./05-security.md)

- **HTTP-only Cookie** — cookie, которое недоступно для JavaScript, что предотвращает кражу токена через XSS-атаки. [см. 02-jwt.md](./02-jwt.md)

- **Hash** — односторонняя функция, которая преобразует данные в фиксированную строку, которую невозможно обратно преобразовать. Используется для хэширования паролей (Argon2id) и refresh tokens (SHA-256).

---

## I

- **Idempotent** — свойство операции, при котором многократное выполнение одной и той же операции даёт тот же результат, что и однократное (например, повторная отправка verification email возвращает 200 OK).

- **Idempotency Key** — уникальный ключ для гарантии идемпотентности операции (например, `POST /v1/auth/resend-verification?idempotency_key=xxx`).

- **IP Address (IPv4/IPv6)** — уникальный адрес устройства в сети. IPv4 — 32-битные адреса (192.168.1.1), IPv6 — 128-битные (2001:0db8:85a3::8a2e:0370:7334).

---

## J

- **JWT (JSON Web Token)** — стандарт открытого стандарта (RFC 7519) для создания токенов доступа, содержащих информацию о пользователе в формате JSON. [см. 02-jwt.md](./02-jwt.md)

- **JTI (JWT ID)** — уникальный идентификатор токена (UUIDv7), используемый для отслеживания и инвалидации токенов. [см. 02-jwt.md](./02-jwt.md)

- **JWT Blacklist** — список отозванных JWT ID (jti), хранящийся в Redis с TTL, равным оставшемуся времени жизни токена.

---

## L

- **Load Balancer** — устройство или программное обеспечение, которое распределяет входящий трафик между несколькими серверами для балансировки нагрузки и повышения отказоустойчивости.

- **Login Attempts** — таблица в базе данных, которая логирует все попытки входа (успешные и неуспешные) для аудита и защиты от атак. [см. 03-database.md](./03-database.md)

---

## M

- **Mailbox provider** — сервис для отправки email (SendGrid, AWS SES, Mailgun). В production используется SendGrid или AWS SES.

- **Memory-hard function** — функция, требующая значительного объема памяти для вычисления, делая взлом на GPU/FPGA затратным (Argon2id).

- **MIME-sniffing** — автоматическое определение типа контента браузером, которое может быть использовано для атак. Защита: заголовок `X-Content-Type-Options: nosniff`. [см. 05-security.md](./05-security.md)

---

## N

- **Nodemailer** — библиотека Node.js для отправки email через SMTP.

---

## O

- **OAuth2 / OpenID Connect** — протоколы авторизации и аутентификации, используемые для "Войти через Google/Facebook".

---

## P

- **PEM Format** — формат хранения криптографических ключей (приватных и публичных), заключённый между `-----BEGIN...` и `-----END...`. [см. 08-deployment.md](./08-deployment.md)

- **PGP (Pretty Good Privacy)** — система шифрования и подписи электронной почты.

- **POST, GET, PUT, DELETE** — основные HTTP методы REST API.

---

## R

- **Redis** — хранилище данных в памяти, используемое для кэширования, rate limiting, управления сессиями и очередей. [см. 05-security.md](./05-security.md)

- **Refresh Token Rotation** — механизм, при котором при каждом использовании refresh token генерируется новый токен, а старый инвалидируется (одноразовость). [см. 02-jwt.md](./02-jwt.md)

- **Revocation** — процесс инвалидации токена (пометка как "отозванный"), чтобы он больше не мог быть использован. [см. 02-jwt.md](./02-jwt.md)

- **Row Level Security (RLS)** — механизм PostgreSQL, который ограничивает доступ к строкам таблицы в зависимости от пользователя. [см. 03-database.md](./03-database.md)

- **Rate limit window** — временной интервал для rate limiting (по умолчанию 60000 мс = 1 минута).

---

## S

- **SameSite Cookie** — атрибут cookie, который контролирует, отправляется ли cookie при cross-site запросах:
  - `Strict` — никогда не отправляется при cross-site
  - `Lax` — отправляется только для GET запросов
  - `None` — всегда отправляется (требует `Secure` флаг) [см. 05-security.md](./05-security.md)

- **Secure Cookie** — cookie, которое отправляется только по защищённому HTTPS соединению (флаг `secure: true`). [см. 02-jwt.md](./02-jwt.md)

- **SQL Injection** — атака, при которой злоумышленник внедряет вредоносный SQL-код через входные данные (например, `' OR 1=1 --`). Защита: prepared statements (ORM). [см. 05-security.md](./05-security.md)

- **SSL / TLS** — протоколы шифрования данных при передаче. SSL — старый, TLS — новый (TLS 1.2+, рекомендуется 1.3). [см. 05-security.md](./05-security.md)

- **SSL Termination** — процесс расшифровки HTTPS трафика на load balancer, после чего запрос передаётся на backend по HTTP.

- **SMTP (Simple Mail Transfer Protocol)** — протокол для отправки email сообщений. [см. 06-email.md](./06-email.md)

- **SHA-256** — криптографическая хэш-функция, используемая для хэширования refresh token (хранится только хэш, не оригинальный токен).

- **Single Sign-On (SSO)** — возможность входа в несколько сервисов с помощью одной учётной записи (например, Google Account).

---

## T

- **TLS 1.3** — последняя версия протокола TLS, обеспечивающая максимальную скорость и безопасность.

- **Token Binding** — привязка токена к конкретному IP-адресу и User-Agent, чтобы его нельзя было использовать с другого устройства. [см. 02-jwt.md](./02-jwt.md)

- **Token Theft** — кража токена злоумышленником, которая может быть минимизирована с помощью short-lived tokens, HTTP-only cookies и rotation.

- **Two-Factor Authentication (2FA)** — двухфакторная аутентификация, когда помимо пароля требуется второй фактор (SMS-код, TOTP-приложение, FIDO2 ключ).

---

## U

- **UUID (Universally Unique Identifier)** — универсальный уникальный идентификатор. В проекте используется UUID v7 (time-based), который включает временную метку.

- **User-Agent** — строка, которая идентифицирует браузер, операционную систему и устройство пользователя (например, `Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/128.0`).

- **User-Agent Hash** — SHA-256 хэш от агрегированной информации User-Agent (browser/os/device), без деталей, которые могут идентифицировать пользователя (GDPR compliance).

---

## V

- **Verification Token** — одноразовый токен, отправляемый пользователю на email для подтверждения адреса (TTL = 24 часа). [см. 06-email.md](./06-email.md)

- **Vulnerability Scanning** — автоматическая проверка приложения на известные уязвимости (SQLi, XSS, CSRF и др.).

---

## W

- **XSS (Cross-Site Scripting)** — атака, при которой злоумышленник внедряет вредоносный JavaScript код в страницу другого пользователя. Защита: Content-Security-Policy + sanitize user input. [см. 05-security.md](./05-security.md)

- **X-Frame-Options: DENY** — заголовок безопасности, который запрещает отображение страницы в iframe (защита от clickjacking).

---

## Типы токенов

| Токен | Срок действия | Назначение | Хранение |
|-------|---------------|------------|----------|
| Access Token | 30 минут | API аутентификация | `Authorization: Bearer <token>` |
| Refresh Token | 7 дней | Получение новых access токенов | HTTP-only cookie |
| Verification Token | 24 часа | Подтверждение email | В ссылке на email |
| Password Reset Token | 1 час | Сброс пароля | В ссылке на email |

## База данных

- **CASCADE** — правило удаления, при котором при удалении родительской записи автоматически удаляются все связанные дочерние записи.

- **Foreign Key (FK)** — ссылка на первичный ключ другой таблицы (например, `user_id` в `refresh_tokens` ссылается на `id` в `users`).

- **Index** — специальная структура в базе данных, которая ускоряет поиск по определённому полю (например, `idx_users_email` для быстрого поиска по email).

- **Primary Key (PK)** — уникальный идентификатор записи в таблице (обычно `id`).

- **UUID v7** — тип UUID, который включает в себя временную метку, что делает его упорядоченным и предсказуемым.

## Безопасность

- **Brute Force Attack** — атака методом перебора, когда злоумышленник пытается угадать пароль или токен, отправляя множество запросов. Защита: rate limiting + блокировка аккаунтов.

- **Rate Limiting** — ограничение количества запросов от одного IP или пользователя за определённый период (например, 5 запросов на login за 10 минут). Реализация: Redis. [см. 05-security.md](./05-security.md)

- **Timing Attack** — атака, при которой злоумышленник пытается угадать токен или пароль по времени ответа сервера. Защита: константное сравнение (`crypto.timingSafeEqual()`). [см. 05-security.md](./05-security.md)

- **Webhook** — HTTP callback, который вызывается внешним сервисом при наступлении определённого события (например, SMTP сервер может отправлять bounce notifications).
